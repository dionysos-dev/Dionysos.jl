18 ### Output
19

21
22 ### Algorithm
23
24 We first check if `x` and `y` are both approximately zero, using
25 `isapproxzero(x) && isapproxzero(y)`.
26 If that fails, we check if `x ≈ y`, using Julia's `isapprox(x, y)`.
27 In the latter check we use `atol` absolute tolerance and `rtol` relative
28 tolerance.
29
30 Comparing to zero with default tolerances is a special case in Julia's
31 `isapprox`, see the last paragraph in `?isapprox`. This function tries to
32 combine `isapprox` with its default values and a branch for `x ≈ 0 ≈ y` which
33 includes `x == 0 == y` but also admits a tolerance `ztol`.
34
35 Note that if `x = ztol` and `y = -ztol`, then `|x-y| = 2*ztol` and still
36 `_isapprox` returns `true`.
