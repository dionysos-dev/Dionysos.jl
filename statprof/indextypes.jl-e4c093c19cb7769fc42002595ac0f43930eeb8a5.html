138 """
139 delete(model::ModelLike, index::Index)
140
141 Delete the referenced object from the model. Throw [`DeleteNotAllowed`](@ref) if
142 if `index` cannot be deleted.
143
144 The following modifications also take effect if `Index` is [`VariableIndex`](@ref):
145 * If `index` used in the objective function, it is removed from the function,
146 that is, it is substituted for zero.
147 * For each `func`-in-`set` constraint of the model:
148 - If `func isa VariableIndex` and `func == index` then the
149 constraint is deleted.
150 - If `func isa VectorOfVariables` and `index in func.variables` then
151 * if `length(func.variables) == 1` is one, the constraint is deleted;
152 * if `length(func.variables) > 1` and `supports_dimension_update(set)` then
153 then the variable is removed from `func` and `set` is replaced by
154 `update_dimension(set, MOI.dimension(set) - 1)`.
155 * Otherwise, a [`DeleteNotAllowed`](@ref) error is thrown.
156 - Otherwise, the variable is removed from `func`, that is, it is substituted for
157 zero.
158 """
