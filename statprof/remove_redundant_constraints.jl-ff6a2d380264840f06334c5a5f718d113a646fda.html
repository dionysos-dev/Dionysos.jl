45 ### Output
46
47 `true` if the removal was successful and the list of constraints `constraints`
48 is modified by removing the redundant constraints, and `false` only if the
49 constraints are infeasible.
50
51 ### Notes
52
53 Note that the result may be `true` even if the constraints are infeasible.
54 For example, ``x ≤ 0 && x ≥ 1`` will return `true` without removing any
55 constraint.
56 To check if the constraints are infeasible, use
57 `isempty(HPolyhedron(constraints))`.
58
59 If `backend` is `nothing`, it defaults to `default_lp_solver(N)`.
60
61 ### Algorithm
62
63 If there are `m` constraints in `n` dimensions, this function checks one by one
64 if each of the `m` constraints is implied by the remaining ones.
65
66 To check if the `k`-th constraint is redundant, an LP is formulated using the
67 constraints that have not yet been removed.
68 If, at an intermediate step, it is detected that a subgroup of the constraints
69 is infeasible, this function returns `false`.
70 If the calculation finished successfully, this function returns `true`.
71
72 For details, see [Fukuda's Polyhedra
73 FAQ](https://www.cs.mcgill.ca/~fukuda/soft/polyfaq/node24.html).
