47 """
48 HalfSpace(expr::Num, vars=_get_variables(expr); [N]::Type{<:Real}=Float64)
49
50 Return the half-space given by a symbolic expression.
51
52 ### Input
53
54 - `expr` -- symbolic expression that describes a half-space
55 - `vars` -- (optional, default: `_get_variables(expr)`) if an array of variables
56 is given, use those as the ambient variables in the set with respect
57 to which derivations take place; otherwise, use only the variables
58 that appear in the given expression (but be careful because the
59 order may be incorrect; it is advised to always pass `vars`
60 explicitly; see the examples below for details)
61 - `N` -- (optional, default: `Float64`) the numeric type of the half-space
62
63 ### Output
64
65 A `HalfSpace`.
66
67 ### Examples
68
69 ```jldoctest halfspace_symbolics
70 julia> using Symbolics
71

74 x
75 y
76
77 julia> HalfSpace(x - y <= 2, vars)
78 HalfSpace{Float64, Vector{Float64}}([1.0, -1.0], 2.0)
79
80 julia> HalfSpace(x >= y, vars)

85 x[1:4]

88 HalfSpace{Float64, Vector{Float64}}([-1.0, 1.0, 0.0, 0.0], -0.0)
89 ```

109 ### Algorithm
110
111 It is assumed that the expression is of the form
112 `α*x1 + ⋯ + α*xn + γ CMP β*x1 + ⋯ + β*xn + δ`,
113 where `CMP` is one among `<`, `<=`, `≤`, `>`, `>=` or `≥`.
114 This expression is transformed, by rearrangement and substitution, into the
115 canonical form `a1 * x1 + ⋯ + an * xn ≤ b`. The method used to identify the
116 coefficients is to take derivatives with respect to the ambient variables `vars`.
117 Therefore, the order in which the variables appear in `vars` affects the final
118 result. Note in particular that strict inequalities are relaxed as being
119 smaller-or-equal. Finally, the returned set is the half-space with normal vector
120 `[a1, …, an]` and displacement `b`.
121 """
122 function HalfSpace(expr::Num, vars::AbstractVector{Num}; N::Type{<:Real}=Float64)
123 valid, sexpr = _ishalfspace(Symbolics.value(expr)) # NOTE: this is an internal function
124 if !valid
125 throw(ArgumentError("expected an expression describing a half-space, got $expr"))
126 end
127
128 # compute the linear coefficients by taking first-order derivatives
129 coeffs = [N(Symbolics.value(α)) for α in Symbolics.gradient(sexpr, collect(vars))]
130
131 # get the constant term by expression substitution
132 zeroed_vars = Dict(v => zero(N) for v in vars)
133 β = -N(Symbolics.value(Symbolics.substitute(sexpr, zeroed_vars)))
134
135 return HalfSpace(coeffs, β)
136 end
