6 # With `Iterators.ProductIterator`, everything works except when the
7 # `IteratorSize` of an iterator is not `Base.HasShape{1}` or `Base.HasLength`
8 # which is notably the case for scalars for it is `Base.HasShape{0}` and
9 # multidimensional arrays for which it is `Base.HasShape{N}` where `N` is the
10 # dimension. For instance:
11 # ```julia
12 # julia> collect(Iterators.product(2, 3))
13 # 0-dimensional Array{Tuple{Int64,Int64},0}:
14 # (2, 3)
15 # ```
16 # while we could like it to be a `3`-dimensional array of size `(1, 1)`.
17 # When the user does `@container([2, 3], 1)`, a `DenseAxisArray` of size
18 # `(1, 1)`. Another example:
19 # ```julia
20 # julia> collect(Iterators.product([1 2; 3 4]))
21 # 2×2 Array{Tuple{Int64},2}:
22 # (1,) (2,)
23 # (3,) (4,)
24 # ```
25 # while we need the size to be `(4,)`, not `(2, 2)` when the user does
26 # `@container([i = [1, 2; 3 4]], i^2)`.
27 # Long story short, we want to tried everything as an iterator without shape
28 # while `Iterators.ProductIterator` does care about preserving the shape
29 # when doing the Cartesian product.
30
