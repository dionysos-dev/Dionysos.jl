7 ## Storage of constraints
8 #
9 # All `F`-in-`S` constraints are stored in a vector of `ConstraintEntry{F, S}`.
10 # The index in this vector of a constraint of index
11 # `ci::MOI.ConstraintIndex{F, S}` is given by `model.constrmap[ci.value]`. The
12 # advantage of this representation is that it does not require any dictionary
13 # hence it never needs to compute a hash.
14 #
15 # It may seem redundant to store the constraint index `ci` as well as the
16 # function and sets in the tuple but it is used to efficiently implement the
17 # getter for `MOI.ListOfConstraintIndices{F, S}`. It is also used to implement
18 # `MOI.delete`. Indeed, when a constraint is deleted, it is removed from the
19 # vector hence the index in the vector of all the functions that were stored
20 # after must be decreased by one. As the constraint index is stored in the
21 # vector, it readily gives the entries of `model.constrmap` that need to be
22 # updated.
23
24 """
25 mutable struct VectorOfConstraints{
26 F<:MOI.AbstractFunction,
27 S<:MOI.AbstractSet,
28 } <: MOI.ModelLike
29 constraints::CleverDicts.CleverDict{
30 MOI.ConstraintIndex{F,S},
31 Tuple{F,S},
32 typeof(CleverDicts.key_to_index),
33 typeof(CleverDicts.index_to_key),
34 }
35 end
36
37 A struct storing `F`-in-`S` constraints as a mapping between the constraint
38 indices to the corresponding tuple of function and set.
39 """

193
194 Return a tuple `(g, t)` representing the constraint `f`-in-`s` with the
195 variable `vi` removed. That is, the terms containing the variable `vi` in the
196 function `f` are removed and the dimension of the set `s` is updated if
197 needed (for example, when `f` is a `VectorOfVariables` with `vi` being one of the
198 variables).

202 function remove_variable(f::MOI.VectorOfVariables, s, vi::MOI.VariableIndex)
203 g = remove_variable(f, vi)
204 if length(g.variables) != length(f.variables)
205 return g, MOI.update_dimension(s, length(g.variables))
206 end
207 return g, s
208 end

254 function _throw_if_cannot_delete(
255 v::VectorOfConstraints{MOI.VectorOfVariables,S},
256 vis,
257 fast_in_vis,
258 ) where {S<:MOI.AbstractVectorSet}
259 if MOI.supports_dimension_update(S) || MOI.is_empty(v)
260 return
261 end
262 for fs in values(v.constraints)
263 f = fs[1]::MOI.VectorOfVariables
264 if length(f.variables) > 1 && f.variables != vis
265 for vi in f.variables

288 vis::Vector{MOI.VariableIndex},
