67 """
68 IteratorSize(itertype::Type) -> IteratorSize
69
70 Given the type of an iterator, return one of the following values:
71
72 * `SizeUnknown()` if the length (number of elements) cannot be determined in advance.
73 * `HasLength()` if there is a fixed, finite length.
74 * `HasShape{N}()` if there is a known length plus a notion of multidimensional shape (as for an array).
75 In this case `N` should give the number of dimensions, and the [`axes`](@ref) function is valid
76 for the iterator.
77 * `IsInfinite()` if the iterator yields values forever.
78
79 The default value (for iterators that do not define this function) is `HasLength()`.
80 This means that most iterators are assumed to implement [`length`](@ref).
81
82 This trait is generally used to select between algorithms that pre-allocate space for their
83 result, and algorithms that resize their result incrementally.
84
85 ```jldoctest
86 julia> Base.IteratorSize(1:5)
87 Base.HasShape{1}()
88
89 julia> Base.IteratorSize((2,3))
90 Base.HasLength()
91 ```
