198 """
199 ScalarQuadraticFunction{T}(
200 quadratic_terms::Vector{ScalarQuadraticTerm{T}},
201 affine_terms::Vector{ScalarAffineTerm{T}},
202 constant::T,
203 ) wher {T}
204
205 The scalar-valued quadratic function ``\\frac{1}{2}x^\\top Q x + a^\\top x + b``,
206 where:
207
208 * ``Q`` is the symmetric matrix given by the vector of [`ScalarQuadraticTerm`](@ref)s
209 * ``a^\\top x`` is a sparse vector given by the vector of [`ScalarAffineTerm`](@ref)s
210 * ``b`` is the scalar `constant::T`.
211
212 ## Duplicates
213
214 Duplicate indices in `quadratic_terms` or `affine_terms` are accepted, and the
215 corresponding coefficients are summed together.
216
217 In `quadratic_terms`, "mirrored" indices, `(q, r)` and `(r, q)` where `r` and
218 `q` are [`VariableIndex`](@ref)es, are considered duplicates; only one needs to
219 be specified.
220
221 ## The 0.5 factor
222
223 Coupled with the interpretation of mirrored indices, the `0.5` factor in front
224 of the ``Q`` matrix is a common source of bugs.
225
226 As a rule, to represent ``a * x^2 + b * x * y``:
227
228 * The coefficient ``a`` in front of squared variables (diagonal elements in
229 ``Q``) must be doubled when creating a [`ScalarQuadraticTerm`](@ref)
230 * The coefficient ``b`` in front of off-diagonal elements in ``Q`` should be
231 left as ``b``, be cause the mirrored index ``b * y * x`` will be implicitly
232 added.
233
234 ## Example
235
236 To represent the function ``f(x, y) = 2 * x^2 + 3 * x * y + 4 * x + 5``, do:
237
238 ```jldoctest
239 julia> x = MOI.VariableIndex(1);
240
241 julia> y = MOI.VariableIndex(2);
242
243 julia> constant = 5.0;
244
245 julia> affine_terms = [MOI.ScalarAffineTerm(4.0, x)];
246
247 julia> quadratic_terms = [
248 MOI.ScalarQuadraticTerm(4.0, x, x), # Note the changed coefficient
249 MOI.ScalarQuadraticTerm(3.0, x, y),
250 ]
251 2-element Vector{MathOptInterface.ScalarQuadraticTerm{Float64}}:
252 MathOptInterface.ScalarQuadraticTerm{Float64}(4.0, MOI.VariableIndex(1), MOI.VariableIndex(1))
253 MathOptInterface.ScalarQuadraticTerm{Float64}(3.0, MOI.VariableIndex(1), MOI.VariableIndex(2))
254
255 julia> f = MOI.ScalarQuadraticFunction(quadratic_terms, affine_terms, constant)
256 5.0 + 4.0 MOI.VariableIndex(1) + 2.0 MOI.VariableIndex(1)² + 3.0 MOI.VariableIndex(1)*MOI.VariableIndex(2)
257 ```
258

299
300 ## `args`
301
302 The vector `args` contains the arguments to the nonlinear function. If the
303 operator is univariate, it must contain one element. Otherwise, it may contain
304 multiple elements.
305

307
308 * A constant value of type `T<:Real`

313

315

321 [`optimize!`](@ref) is called.
322

324

326

328 julia> x = MOI.VariableIndex(1)
329 MOI.VariableIndex(1)

331 julia> MOI.ScalarNonlinearFunction(
332 :^,
333 Any[MOI.ScalarNonlinearFunction(:sin, Any[x]), 2],
334 )

356 stack, result_stack = Any[f], Any[]

358 arg = pop!(stack)
359 if arg isa ScalarNonlinearFunction
360 # We need some sort of hint so that the next time we see this on the
361 # stack we evaluate it using the args in `result_stack`. One option
362 # would be a custom type. Or we can just wrap in (,) and then check
363 # for a Tuple, which isn't (curretly) a valid argument.
364 push!(stack, (arg,))

677
678 ## `args`
679
680 The vector `args` contains the scalar elements of the nonlinear function. Each
681 element must be a [`ScalarNonlinearFunction`](@ref), but if you pass a
682 `Vector{Any}`, the elements can be automatically converted from one of the
683 following:
684
685 * A constant value of type `T<:Real`
686 * A [`VariableIndex`](@ref)
687 * A [`ScalarAffineFunction`](@ref)
688 * A [`ScalarQuadraticFunction`](@ref)
689 * A [`ScalarNonlinearFunction`](@ref)
690
691 ## Example
692
693 To represent the function ``f(x) = [sin(x)^2, x]``, do:
694
695 ```jldoctest
696 julia> x = MOI.VariableIndex(1)
697 MOI.VariableIndex(1)
698
699 julia> g = MOI.ScalarNonlinearFunction(
700 :^,
701 Any[MOI.ScalarNonlinearFunction(:sin, Any[x]), 2.0],
702 )
703 ^(sin(MOI.VariableIndex(1)), 2.0)
704
705 julia> MOI.VectorNonlinearFunction([g, x])
706 ┌ ┐
707 │^(sin(MOI.VariableIndex(1)), 2.0)│
708 │+(MOI.VariableIndex(1)) │
709 └ ┘
710 ```
711
712 Note the automatic conversion from `x` to `+(x)`.
713 """
714 struct VectorNonlinearFunction <: AbstractVectorFunction
715 rows::Vector{ScalarNonlinearFunction}
716 end
717
718 output_dimension(f::VectorNonlinearFunction) = length(f.rows)
719
720 function constant(f::VectorNonlinearFunction, ::Type{T}) where {T}
721 return zeros(T, output_dimension(f))
722 end

727 return f.rows == g.rows

857 # For affine and quadratic functions, terms are compressed in a dictionary using
858 # `_dicts` and then the dictionaries are compared with `dict_compare`
859 function dict_compare(d1::Dict, d2::Dict{<:Any,T}, compare::Function) where {T}
860 for key in union(keys(d1), keys(d2))
861 if !compare(Base.get(d1, key, zero(T)), Base.get(d2, key, zero(T)))
862 return false
863 end
864 end
865 return true
866 end

868 # Build a dictionary where the duplicate keys are summed
869 function sum_dict(kvs::Vector{Pair{K,V}}) where {K,V}
870 d = Dict{K,V}()
871 for (key, value) in kvs
872 d[key] = value + Base.get(d, key, zero(V))
873 end
874 return d
