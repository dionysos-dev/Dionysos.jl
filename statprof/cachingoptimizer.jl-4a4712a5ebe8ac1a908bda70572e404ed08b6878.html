62 """
63 CachingOptimizer
64
65 `CachingOptimizer` is an intermediate layer that stores a cache of the model and
66 links it with an optimizer. It supports incremental model construction and
67 modification even when the optimizer doesn't.
68
69 ## Mode
70
71 A [`Utilities.CachingOptimizer`](@ref) has two modes of operation:
72 [`Utilities.AUTOMATIC`](@ref) and [`Utilities.MANUAL`](@ref). See their
73 docstrings for details.
74
75 Use [`Utilities.mode`](@ref) to query the mode of a
76 [`Utilities.CachingOptimizer`](@ref).
77
78 ## State
79
80 A [`Utilities.CachingOptimizer`](@ref) may be in one of three possible states:
81 [`NO_OPTIMIZER`](@ref), [`Utilities.EMPTY_OPTIMIZER`](@ref), and
82 [`Utilities.ATTACHED_OPTIMIZER`](@ref). See their docstrings for details.
83
84 Use [`Utilities.state`](@ref) to query the state of a
85 [`Utilities.CachingOptimizer`](@ref).
86
87 ## Constructor with optimizer
88
89 ```julia
90 CachingOptimizer(cache::MOI.ModelLike, optimizer::AbstractOptimizer)
91 ```
92
93 Creates a `CachingOptimizer` in [`AUTOMATIC`](@ref) mode, with the optimizer
94 `optimizer`.
95
96 The type of the optimizer returned is
97 `CachingOptimizer{typeof(optimizer),typeof(cache)}` so it does not support the
98 function [`Utilities.reset_optimizer(::CachingOptimizer, new_optimizer)`](@ref)
99 if the type of `new_optimizer` is different from the type of `optimizer`.
100
101 ## Constructor without optimizer
102
103 ```julia
104 CachingOptimizer(cache::MOI.ModelLike, mode::CachingOptimizerMode)
105 ```
106
107 Creates a `CachingOptimizer` in the [`NO_OPTIMIZER`](@ref)
108 [`Utilities.CachingOptimizerState`](@ref) and the
109 [`Utilities.CachingOptimizerMode`](@ref) `mode`.
110
111 The type of the optimizer returned is
112 `CachingOptimizer{MOI.AbstractOptimizer,typeof(cache)}` so it _does_ support the
113 function `reset_optimizer(::CachingOptimizer, new_optimizer)` if the type of
114 `new_optimizer` is different from the type of `optimizer`.
115 """

171 function _copy_optimizer_attributes(m::CachingOptimizer)
172 @assert m.state == EMPTY_OPTIMIZER
173 for attr in MOI.get(m.model_cache, MOI.ListOfOptimizerAttributesSet())
174 # Skip attributes which don't apply to the new optimizer.
175 if attr isa MOI.RawOptimizerAttribute
176 # Even if the optimizer claims to `supports` `attr`, the value
177 # might have a different meaning (for example, two solvers with `logLevel`
178 # as a RawOptimizerAttribute). To be on the safe side, just skip all
179 # raw parameters.
180 continue
181 elseif !MOI.is_copyable(attr) || !MOI.supports(m.optimizer, attr)::Bool
182 continue
183 end
184 value = MOI.get(m.model_cache, attr)
185 optimizer_value = map_indices(m.model_to_optimizer_map, attr, value)
186 MOI.set(m.optimizer, attr, optimizer_value)
187 end
188 return
189 end
