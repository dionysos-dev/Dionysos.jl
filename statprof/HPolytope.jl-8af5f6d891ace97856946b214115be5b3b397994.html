1 """
2 HPolytope{N, VN<:AbstractVector{N}} <: AbstractPolytope{N}
3
4 Type that represents a convex polytope in constraint representation, i.e., a
5 bounded set characterized by a finite intersection of half-spaces,
6
7 ```math
8 P = ⋂_{i = 1}^m H_i,
9 ```
10
11 where each ``H_i = \\{x ∈ ℝ^n : a_i^T x ≤ b_i \\}`` is a
12 half-space, ``a_i ∈ ℝ^n`` is the normal vector of the ``i``-th
13 half-space and ``b_i`` is the displacement.
14 It is assumed that ``P`` is bounded (see also [`LazySets.HPolyhedron`](@ref),
15 which does not make such an assumption).
16
17 ### Fields
18
19 - `constraints` -- vector of linear constraints
20 - `check_boundedness` -- (optional, default: `false`) flag for checking if the
21 constraints make the polytope bounded; (boundedness is
22 a running assumption for this type)
23
24 ### Notes
25
26 A polytope is a bounded polyhedron.
27
28 Boundedness is a running assumption for this type. For performance reasons,
29 boundedness is not checked in the constructor by default. We also exploit this
30 assumption, so a boundedness check may not return the answer you would expect.
31
32 ```jldoctest isbounded
33 julia> P = HPolytope([HalfSpace([1.0], 1.0)]); # x <= 1
34
35 julia> isbounded(P) # uses the type assumption and does not actually check
36 true
37
38 julia> isbounded(P, false) # performs a real boundedness check
39 false
40 ```
