# Velocity-level Symbolic Control of Underactuated Mechanical Systems

Reproducibility capsule of the ECC 2027 paper by R. Bertollo, J. Calbert and R. M. Jungers.

It regenerates Table I and Figs. 4–5 of the paper, which compare two approaches (Fig. 1 of the
paper): the baseline (B) commands torques or forces and abstracts the full model, and the
proposed approach (P) commands velocities and abstracts the reduced model under the impulse
budget. `params_e1.md` and `params_e2.md` list every parameter, including those left out of the
paper. All values are in SI units.

## Run

On CodeOcean, press *Reproducible Run*. It runs `./run` and writes the results to `/results`.
Locally, from this folder inside the Dionysos.jl repository:

```bash
./run                                          # instantiate, then run everything
julia --project=. --threads=auto run_all.jl    # the same, once instantiated
julia --project=. --threads=auto experiments/E1_pendulum.jl   # one experiment
```

| Variable | Default | Effect |
|---|---|---|
| `SAMPLES=n` | 3 | median wall time of `n` rounds (the baseline (B) of E2 is timed once) |
| `FIGURES=0` | on | skip the plots and animations |
| `RESULTS_DIR=path` | `results/` | output folder (`/results` on CodeOcean) |

A full run takes about 15 minutes, mostly for the abstraction of (B) on the cart-pole, built in
parallel. The timings in the paper come from a 14-thread laptop (`results/environment.txt`).

Both approaches use Dionysos's uniform grid abstraction solver. Table I and Figs. 4–5 are copied
from `table_e*.tex` and `fig_e*.pdf`, and the numbers in the text are in `numbers.tex`. The
`.png` and `.gif` files are not in the paper.

## Controllers and replays

At each sampling instant `kτ`, the controller reads the cell `p` of the state and returns the
input held until the next instant (Fig. 1 of the paper):

- (B): a torque or force, `Γ_k = Ĉ_B(p)`.
- (P): a velocity command, `u_k = Ĉ(p, v)`, where the memory `v = u_{k-1}` is the previous
  command, and `v = 0` at the start. The impulse budget restricts which commands may follow `v`.

Each controller is replayed on the continuous-time model, integrated with RK4:

- (B) (`replay_torque`, `replay_force`): the input is held over each period.
- (P) with ideal impulses (`replay_reduced`, Assumption 1): the velocity jumps to each new
  command. The replay reports the impulses `γ_k` and the hold torque or force `Γ_hold`, the
  columns `max|γ_k|` and `max|Γ|` of Table I.
- (P) with an inner PI loop (`replay_inner_loop`, E2): a saturated PI loop with anti-windup
  tracks the commands every 1 ms under `Γ_max`. This replay is not certified. It runs from the
  start of Fig. 5 (green) and from every cell where the controller is defined, starting at rest.

## Checks

The run stops with an error, or warns, if a result contradicts the paper:

- the replays of (P) reach the target within the impulse budget (E1, E2), the replay of (B)
  reaches the target (E1), and a solved (B) stays within its force limit (E2);
- the steps of (P) from the bottom are the fewest possible, by a breadth-first search on the
  states `(p, v)` of the abstraction Ŝ (E1);
- (P) reaches the target from every cell where its controller is defined, starting at rest, with
  ideal impulses and with the inner PI loop (E2, warning).

## Environment

- Julia 1.12 (results from 1.12.5); packages pinned by `Project.toml` and `Manifest.toml`.
- Dionysos is loaded from source two folders up (`path = "../.."` in the manifest). Locally this
  is the enclosing repository. On CodeOcean, `environment/postInstall` clones Dionysos.jl at a
  fixed commit and installs the packages when the environment is built, so a run needs no
  network.
- `environment.txt` records the date, Dionysos commit, Julia version and machine of each run.

## Layout

```
run, run_all.jl           entry points
common.jl                 shared helpers
Project.toml, Manifest.toml
experiments/              one script per experiment
environment/postInstall   CodeOcean build step
results/                  outputs, regenerated by each run
```
